# mallow

A little helper on your Windows desktop: press a shortcut, circle something on your screen, and ask. It answers in a short note, points at what it's talking about and marks it up in red pencil. It runs on your own Claude plan through Claude Code, so there's no API key.

## Download

Get the latest **mallow-setup-x.y.z.exe** from [Releases](../../releases/latest) and run it. It installs just for you, with no admin rights needed, and starts the setup window: it installs Claude Code if needed and signs you in with your own Claude account (Pro or Max).

mallow keeps itself up to date: new versions download in the background and install the next time it restarts.

The installer isn't code-signed yet, so Windows SmartScreen may warn the first time. Click "More info" and then "Run anyway".

## Requirements

- Windows 10 or 11
- A Claude Pro or Max plan

This repository only holds the installers and release notes.
